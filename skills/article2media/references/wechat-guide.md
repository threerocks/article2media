# 公众号指南（--layout wechat）

`--layout wechat` 把同一份 content.json 排成一篇能直接粘贴进公众号编辑器的图文：

| 输出 | 用途 |
|---|---|
| `article.html` | 预览页（手机宽度）。顶部「复制到公众号」按钮把正文以富文本写进剪贴板 |
| `article-body.html` | 只有正文的 HTML 片段（同样可粘贴） |
| `images/fig-1A.png …`、`hero.png` | 每张图表的 3 倍图；粘贴后某张图缺了，就从这里拖进去 |
| `cover-2.35x1.png`、`cover-1x1.png` | 头图（2.35:1）和分享卡片 / 次条封面（1:1） |
| `wechat.md` | 标题、摘要、原文信息和发布步骤 |

## 它怎么做到能粘贴

公众号编辑器会去掉 `<style>`、class、外部 CSS、网络字体和脚本。所以：
- 所有样式都从主题算出来后写成内联 `style`，颜色统一成 rgb；
- 标题、正文改用系统字体（苹方 / 宋体），网络字体只保留在图表图片里；
- 图表和插画先截成 PNG，再以 base64 内嵌，粘贴时编辑器会自己上传，不需要图床；
- 不用 `ul/li`、CSS Grid 和 position：列表写成段落，表格面板用 `<table>`；
- 渐变文字（background-clip: text）没法粘贴，改成渐变的第一种颜色。

## 写法

- 正文直接用长图的内容，不需要另写。结构：题图（有封面插画时）→ 来源 → 导语 → 本文要点 → 每部分标题 → 各节（标题、正文、要点、两张图、面板、金句）→ 收束句 → 来源说明。
- `wechat.title`：公众号标题最多 64 字，建议 20–30 字，信息完整、不标题党。比如"2027 年最赚钱的 AI 生意：一个人，做一支创意团队"。
- `wechat.digest`：摘要最多 120 字，说清"这篇能给你什么"。不写时用第一页导语，超长会截断。
- 外链在公众号正文里不能点击，原文链接以纯文本放在文末。

## 检查

- 打开 `article.html` 看一遍：手机宽度下段落、图、表是否清楚。
- 版面检查只看图表内部；正文交给编辑器排，不存在溢出问题。
- 粘贴后在公众号后台用「预览」发到手机上看一眼，这是最终效果。深色主题在微信深色模式下会被系统再调一次色。
